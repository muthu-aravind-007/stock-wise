# StockWise ⚡

**Empowering Smarter Inventory Decisions**

StockWise is a modern inventory management web application built with **React**, **Tailwind CSS**, and **Supabase**. It helps businesses track products, manage suppliers, and monitor stock in real-time, all from a sleek, responsive dashboard.

---

## 🚀 Features

- **Responsive Dashboard**: Bar and pie charts to visualize stock and sales data.
- **Products Management**: Add, edit, and delete products easily.
- **Suppliers Management**: Track suppliers and their products.
- **Transactions**: Manage stock in and stock out efficiently.
- **Dark/Light Mode**: Switch themes effortlessly.
- **User Profiles**: Login, logout, and manage account settings.

---

## 🛠 Tech Stack

- **Frontend**: React, Tailwind CSS, Lucide Icons  
- **Backend**: Supabase (Auth + Database)  
- **Routing**: React Router DOM  
- **Charts & Visualizations**: Recharts
